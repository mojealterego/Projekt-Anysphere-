# Projekt Anysphere

Niezależny projekt platformy agentowego wytwarzania oprogramowania. Repozytorium nie jest oficjalnym projektem Anysphere Inc. ani Cursor.

## Cel
Zbudowanie bezpiecznego, rozszerzalnego środowiska AI-assisted software engineering: analiza repozytoriów, planowanie zmian, izolowane wykonanie, weryfikacja i kontrolowany code review.
